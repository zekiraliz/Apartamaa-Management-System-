# Web-Based Apartment Management System for Haramaya University

## Project Overview

The Web-Based Apartment Management System is designed to automate and simplify apartment allocation and management at Haramaya University.

## Objectives

- Automate apartment allocation
- Manage university staff information
- Apply eligibility and priority rules
- Reduce manual work and errors
- Improve transparency and efficiency
- Generate useful reports

## User Roles

- Housing Office / Administrator
- University Staff
- Management

## Main Features

- User authentication
- Staff profile management
- Apartment management
- Eligibility and priority calculation
- Apartment allocation
- Notifications
- Reports

## Technologies

- HTML
- CSS
- JavaScript
- Python
- SQL / Database
